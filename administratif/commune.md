# Commune

<https://bdtopoexplorer.ign.fr/commune>

Les objets de la table BDTopo `Commune` sont convertis en relation avec les tags suivants :

- `type` = `boundary`
- `boundary` = `administrative`
- `admin_level` = `8`

## Géométrie

Type de géométrie : MultiPolygone 2D

à convertir en relation OSM
