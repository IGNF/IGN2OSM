# Haie

<https://bdtopoexplorer.ign.fr/haie>

Les objets de la table BDTopo `Haie` sont convertis en chemins isolés avec les attributs `barrier`=`hedge`.

Remarque : des haies sont également présentes sous forme surfaciques, dans la classe `Zone de végétation`. Une déduplication peut être nécessaire.

## Géométrie

Type de géométrie : Ligne 2D

à convertir en chemin OSM
